# PocketLab

A minimal Android app scaffold for running AI-generated Python experiments locally on a phone.

## Core idea

ChatGPT/Claude invents or edits the Python tool. PocketLab runs it locally on Android and returns organized results you can paste back into ChatGPT/Claude.

## Stack

- Kotlin
- Jetpack Compose
- Chaquopy 17.0.0
- Embedded Python 3.11

## Open

Open this folder in Android Studio and run the app module.

See `docs/BUILD_AND_RUN.md`.
